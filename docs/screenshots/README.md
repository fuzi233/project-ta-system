# Screenshot Checklist

Store assessment screenshots in this directory using the following names.

## Required files

1. `01-login-register.png`  
   Show role-based register/login form on `index.jsp`.

2. `02-ta-jobs-and-apply.png`  
   Show TA page with job list and successful application response.

3. `03-ta-status-query.png`  
   Show TA status query result containing at least one application.

4. `04-mo-create-job.png`  
   Show MO page and successful job creation response.

5. `05-mo-screening.png`  
   Show MO candidate filtering result.

6. `06-mo-status-update.png`  
   Show MO status update result.

7. `07-admin-workload.png`  
   Show Admin workload dashboard response and threshold value.

8. `08-acceptance-script-pass.png`  
   Show terminal output with all acceptance steps passed.

9. `09-mvn-test-pass.png`  
   Show terminal output for `mvn test` pass.

## Tips

- Use browser zoom at 100% so response text is readable.
- Keep timestamp visible when possible.
- Do not mask jobId/applicationId used in demonstration.
